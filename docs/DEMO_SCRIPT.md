# 120 秒录屏脚本（候选人需实际录制，交付包不含假视频）

**0–15 秒：** 打开 Web 产品，说明「单股循证诊断」；展示贵州茅台 600519、报告截止日期、未经审计和非实时数据标识。

**15–40 秒：** 依次指出营业收入 +1.47%、归母净利润 -1.95%、营业成本 +21.81% 与毛利率变化。点击「经营质量」视角、查看收入与利润方向冲突。

**40–65 秒：** 点击经营现金流 KPI → E04 详情。展示真实金额 70,690,750,119.06 元和 13,119,061,031.33 元，阅读财务公司的原因解释，打开原始 PDF 链接。

**65–85 秒：** 切换「模拟来源冲突」，展示收入和毛利率停止计算、利润仍保留。切回标准状态。

**85–105 秒：** 研究助手中提问「现金流暴涨是否代表卖得更好？」→ 点击返回的证据项，检查问答不是凭空给出推荐。

**105–120 秒：** 展示估值维度的「未知」、手动价格情景计算，结尾展示三份原始正式公告与没有做的事。

录制建议：桌面浏览器 1440×900 左右，1280×720 或更高分辨率，尽量使用真实点击和解说，不靠 PPT；录制后确认视频实际长度在 60–180 秒。
