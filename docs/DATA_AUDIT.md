### 口径重点

1. **营业收入**是合并报表「营业收入」字段（2026H1 907.03 亿元），区别于报告管理层叙述里的「营业总收入」（2026H1 922.78 亿元，含金融业务相关收入）。系统选用前者，避免同字段名混用。
2. **经营现金流 +438.84%**是原始财务同比，但 2026 半年报披露了财务公司吸收成员单位存款增加及同业存款等因素；不能将现金净流入幅度理解成酒类销售回款增长幅度。
3. **合并报表营业毛利率**由本年同期期次的 `（营业收入-营业成本）/营业收入` 计算，与酒类单独板块毛利率不是同一口径。本系统不将二者混比。
4. **合同负债 -60.31%**是资产负债表同类项目的两个时点余额比较，不是“2026H1 同比”。半年报说明受到销售模式和预收款政策调整影响。
5. **估值**：2025FY EPS = 65.66 元/股，仅能与用户自己输入的假设价进行「情景静态 PE」演示；不得将其显示为真实当前 PE。
6. **商品调价公告**：i茅台零售价 1539 → 1639 元/瓶；销售合同价 1269 → 1369 元/瓶，均为特定商品的定价，非证券股价。影响大小暂无可验证数据。

所有字段具体溯源请见 `data/filings.json`，其逐字段保留 `{raw,unit,period,source,page,location,scope}`。HTML 证据抽屉动态展示该字段结构及原文 URL。

## 两种数据确定性

- **可以确定**：报告原文披露了哪些数字和公司观点；按 Decimal 的算术结果；原文是否声明“未经审计”。
- **不能据此确定**：未来走势、真实同行排名、当前股价与估值、终端动销、涨价带来的实际利润增幅；所有这些维度在 UI 里有明确「证据缺口」。
