## Render 快速发布操作

1. 创建 GitHub 仓库，上传**项目根目录中的文件**。不要提交含真实密钥的 `.env`。
2. 在 Render Dashboard 选择 New → Web Service → 关联仓库，或者用 Blueprint 选择仓库的 `render.yaml`。
3. 启动命令 `python server.py`。如需手工设置，`HOST=0.0.0.0`，端口使用平台传入的 `PORT`。
4. 服务成功后，检查平台生成的域名与 `/api/health`，然后在手机或无痕窗口完整测试。
5. 只有真实存在且公众可访问的域名、仓库链接才可填写提交系统。

平台套餐、菜单和发布流程可能发生变化；以部署时页面为准。
