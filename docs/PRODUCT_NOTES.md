# 产品说明 / 设计决策（面试讲述备忘）

## 定位与边界

选择单股而不是股票池，聚焦「看得懂、能追溯、知道不知道」三件事。目标用户是研究个人 A 股的初学投资者，不是量化研究员。本产品不做投资评级。

## 典型用户故事

研究者看到 2026 年半年报「经营现金流同比增长 438.84%」，想知道它是不是公司经营变好。打开 E04 后，可同时看到源字段、同期期次、管理层关于财务公司的释义，以及「下一步需核查什么」，而不是拿到“现金流强，建议买入”的虚假结论。

## 关键交互设计

- 一级信息：四张指标卡，不用单一综合分给公司贴标签。
- 二级研究：经营、财务、估值、行情、行业、事件、风险七维可切换，未验证内容不会被隐藏。
- 三级追溯：每条证据通过数字 ID 进入抽屉，展示元级原始数值、PDF 页码、公式、待验证项。
- 问答：先通过可选 LLM 或本地多意图规则选择合法证据 ID；确定性引擎按事实 / 谨慎推断 / 未知 / 下一步核验生成有出处的答案，避免自由生成未核实数字。
- 数据异常：原始来源异常先于计算引擎生效，因此 UI 的数字与文案相应降级。

## 面试可以演示的三个高价值瞬间

1. **矛盾**：收入 +1.47%、成本 +21.81%、归母利润 -1.95%——怎么理解经营质量？
2. **分层**：现金流 +438.84% 是事实，主要驱动来自财务公司是管理层的解释，终端销售因此更强仍无法验证。
3. **拒答**：如果问“现在 PE 多少、贵不贵”，产品不填编造价格；只有公开的 2025EPS + 用户假设价可以运算情景 PE。

## 下一轮迭代优先级

P0：接入有授权的扶摇实时/历史行情，统一时点与复权口径；自动校验财报字段映射。
P1：接入同报告期同行样本与跨源一致性验证，真实地完成行业分位比较。
P1：对接披露更新监控，对字段 stale 作基于交易日/报告期的新旧判定，而不只是模拟。
P2：新增用户阅读进度、证据批注、研究报告导出。

不宜优先做所谓“AI 评分”或买卖推荐：现阶段会掩盖数据来源不足。
