## 手动验收清单（部署后由候选人逐条检查）

- [ ] 首页 KPIs 与 PDF 同期数据一致。
- [ ] 选择「财务趋势」，半年和全年图表没有被混合。
- [ ] E04 可展示财务公司导致现金流增加的披露原因。
- [ ] E05 明确合同负债是「上年末 → 本期末」，不是半年同比。
- [ ] E08 假设价测试显示情景静态 PE，没有把输入价当作真实股价。
- [ ] 行情特征与同行排名没有虚构数字。
- [ ] 用户自然语言问答不回复确定性股价涨跌 / 直接买卖建议。
- [ ] 切换 missing / conflict / stale / offline 后，相关指标不会悄悄恢复数值。
- [ ] 在无痕窗口验证线上首页、证据详情、问答和公告链接都可点开。
- [ ] 通过手机浏览器验证交互 / 抽屉布局（建议）。
