# 浏览器交互冒烟验收（2026-10-08，V1.2）

## 验证方法与限制

使用系统 Chromium + Playwright 执行 `python tests/ui_smoke.py`。该脚本加载项目**真实 HTML、CSS、JS**，并将浏览器 `fetch` 映射到项目 `diagnostic.py` 的实际数据计算函数，而不是预填任意 API 模拟结果。

因当前沙盒浏览器无法直接访问本地 HTTP 地址，所以这属于**真实前端 + 真实业务计算、mock 网络层**测试，不等于公网 URL 端到端验收。真实后端 HTTP 路由另由 unittest HTTP 集成测试覆盖。仓库公开部署后仍应真实复测公网地址。
