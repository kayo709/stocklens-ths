# AI 使用与验证记录

## 使用说明

- 开发辅助：ChatGPT（GPT-6）参与理解三道测评题、拆解产品流程、设计前端交互、编写后端 / 前端 / 测试代码、协助比对公司公告，以及撰写交付说明。
- 数据检索：公开网页与公司官方披露 PDF；不是大模型参数记忆中的股票数据。所有进入计算引擎的基础数字都落盘在 `data/filings.json` 并附原始 URL 与页码。
- 产品运行时：**默认离线规则路由**；填写 `OPENAI_API_KEY` 后可调用 OpenAI 做意图和证据 ID 选择。LLM 不负责计算和生成财务事实。
- **未声称**已经在真实在线密钥环境验证 LLM 供应商接口。没有任何密钥包含在交付物中。
- 本日志记录的是本交付项目实际执行的模型协作与核验。**不代表候选人已独立检查所有原文或自主编写过本项目。提交者仍应亲自运行、阅读、修改并验收。**

## AI 对产品职责边界

**LLM 可做：** 将用户问题与已有证据关联、挑选优先阅读的证据 ID；在未来扩展中可对已有材料进行受约束归纳（当前版本未实现该类自由归纳）。

**LLM 不可做：** 确定财务数字、改写原始字段、自动给出行业排名、输出确定性收益、绕开数据异常、返回预设 ID 以外的“新”证据。

**确定性计算引擎做：** 金额同比、毛利率、余额变化、手动情景静态 PE 和分母为零处理。

**数据与证据层做：** 原始字段管理、披露日期、期次、单位、来源页码、公司观点 / 待验证的分类。

**用户做：** 查看原始公告、对照信息、决定研究方向和是否采纳观点。

- 原实现计算 ROE 的 `16.75 / 17.89 - 1` 相对变化，虽然未显示于主页，却在 API 中可能误导；修复为 `16.75 - 17.89 = -1.14 个百分点`，增加针对性测试。
- 原实现对于只有文本来源、没有数值字段的 E10/E12，在源整体失效时未降级；已按来源依赖和状态修正，同时确保只有 CFO 字段缺失时不会阻断正常的行业文字来源。
- 问答原实现只提示阅读证据卡，缺少直接回答；现为有限的字段级模板化解释，并保留跳转证据。仍明确区分离线规则模式和可选的真实 LLM 证据路由。
